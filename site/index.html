A green robot floats over your web app while you build it. Drag its hand onto the thing you mean, write a note, and it lands in your agent's chat with a screenshot, the exact element and the page's errors. The answer comes back through the robot.

Try it right here

  1. Drag the robot's green hand onto something in the app below.
  2. Write what should change, like “make this green and bigger”.
  3. Send, and watch the robot report back as “Claude” makes the change.

In this demo the replies are scripted and nothing leaves your browser. In your own app, the note goes to your local inbox and the real Claude or Cursor agent picks it up.

What your agent gets

The picture

A screenshot of the window with what you pointed at outlined, and a sharper close-up of it.

The exact element

The React components it sits in, a CSS path, its text and its box, so the agent goes straight to the right file.

What went wrong

The page you were on and the console's recent errors and warnings, without you copying anything.

Why it exists

Telling an agent what's wrong with a screen usually means a screenshot, a crop, a paste, and a paragraph about where on the page you mean. Then you go back and do it again for the next thing.

With the robot you point, type, and keep going. Send ten notes in a row while the agent works through them, and see each one go from got it to done without leaving your app. It works for teammates and clients on a staging site too: they point and write, and it reaches your chat.

Install

Claude Code

Add the plugin, then let Claude put the robot in your app.

/plugin marketplace add obsidiandeep-ops/feedback-robot
/plugin install feedback-robot@obsidiandeep
/feedback-robot:setup

Cursor

Install feedback-robot from the Cursor Marketplace, then ask the agent to “set up the feedback robot”.

By hand

Next.js, Vite, Express, or any stack with a script tag.

npm install -D @obsidiandeep/feedback-robot
npx feedback-robot init

Wiring for your stack →

Messages and screenshots stay on your machine. The robot runs in development only unless you switch it on.
